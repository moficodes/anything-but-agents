# PixiJS 2D Viewport Engine and Asymmetric Timed Class Combat

`cmd/dungeon2d` uses a PixiJS v8 2D WebGL/Canvas rendering engine (with a deterministic Canvas2D fallback for headless verification) featuring a scrolling camera viewport over 8 multi-route dungeon floors (`Floor 1` to `Floor 8`), dynamic torchlight and fog-of-war, and real-time A* enemy pathfinding. Instead of turn-based bump-to-clash combat with identical stats, the three `Hero Classes` (**Paladin**, **Ranger**, and **Wizard**) are balanced asymmetrically across max HP, armor mitigation, move speed, attack range, attack-speed cooldowns, and a tactical `Class Skill`, paired with dual-thumb mobile portrait controls (left movement D-pad/tap-pathing, right Attack & Class Skill cooldown buttons with auto-nearest and tap-to-focus enemy targeting).
