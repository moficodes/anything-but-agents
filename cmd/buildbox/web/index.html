THE REBEL: HERMETIC CI/CD

Why Run Builds on Agent Substrate?

Traditional CI/CD systems either run unconfined with open outbound Internet access (leaking secrets and risking dependency confusion attacks) or require slow, multi-container workflows where each phase stops and boots from scratch. With Agent Substrate, a build runner holds its warm compiler and dependency cache inside gVisor heap RAM across phases, while the control plane dynamically hot-swaps ActorEgressPolicy on the fly—guaranteeing 100% SLSA L3 hermetic compilation with zero container restarts.

THE AGENT EPIPHANY: PROMPT INJECTION DEFENSE

Phase-Locked Egress Stops Agent Data Exfiltration

When autonomous AI agents execute untrusted Python code or shell commands, prompt injection attacks attempt to phone home to attacker C2 servers or query internal cloud metadata (169.254.169.254). By pairing agent turn loops with ActorEgressPolicy, the orchestrator only enables specific external API hostnames during authorized tool steps, locking the sandbox into Total Airgap while the agent synthesizes answers!
